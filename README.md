# Nvelope

A personal finance management app built with React, TypeScript, Firebase.

Live at [https://www.nvelopes.app](https://www.nvelopes.app)

## Tech Stack

- React
- TypeScript
- Firebase
- Tailwind CSS

Firestore rules are in `firestore.rules`; deploy via Firebase Console.
